Acme API Product Updates
June 14, 2026 New
Webhooks now retry automatically on failure
Webhook deliveries that fail with a 5xx or timeout are now retried up to 5 times with exponential backoff — so transient downtime on your end no longer means lost events. You can see retry history and manually trigger a replay from the dashboard.
June 11, 2026 Improved
Search is 4× faster across large datasets
We rewrote the query engine powering full-text search. For workspaces with more than 50k records, searches now return in under 200ms on average — down from 800ms. No changes needed on your end; existing queries just got faster.
June 9, 2026 New
CSV export now includes custom fields
Any custom fields you've added to records are now included in CSV exports. The column order matches the order shown in your table view, and field names match your labels exactly.
June 5, 2026 Fixed
Pagination no longer skips records under high load
A race condition caused paginated API responses to occasionally skip records when new items were inserted concurrently. This is now fixed — all list endpoints use stable cursor-based pagination.
June 2, 2026 Infrastructure
Reduced P99 latency by 40% in EU regions
We migrated EU workloads to a closer edge location, reducing round-trip times for customers in France, Germany, and the Nordics. No changes to your integration are needed.
